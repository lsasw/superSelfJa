# 93. 视觉语言模型

视觉语言模型（Vision-Language Model, VLM）是多模态 AI 的重要分支，能够同时理解和生成文本与视觉内容。从 CLIP 的图文匹配到 LLaVA 的视觉问答，VLM 正在快速改变 AI 应用的形态。

## 主流 VLM 对比
